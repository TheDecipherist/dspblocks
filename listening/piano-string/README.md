# Milestone 1: does the string stretch?

Three pairs, six seconds each. Same block, same excitation, same decay. The only
difference inside a pair is `B`, the inharmonicity coefficient: `B0` is a
perfectly harmonic string and the other is what a real piano string of that
pitch has.

- **A1, 55 Hz** - harmonic against `B = 1e-3`. The bass is where stiffness is
  strongest and this is the pair where it is obvious.
- **A2, 110 Hz** - harmonic against `B = 6e-4`.
- **A4, 440 Hz** - harmonic against `B = 5e-5`. Treble strings are barely stiff,
  so this pair should be a much smaller difference. If it sounds as different as
  the bass pair, something is wrong.

**What to listen for.** The harmonic one should sound like a plucked string, a
bit like a guitar or a clavinet. The stiff one should have the metallic,
slightly detuned shimmer a piano has, and the decay should sound less like one
note and more like a small cloud of them. Nothing here is a piano yet - there is
no hammer, no unison strings, no soundboard - so judge the STRETCH and nothing
else.

Levels are unnormalised on purpose, so a loudness difference you hear is one the
model causes.
